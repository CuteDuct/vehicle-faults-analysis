# 车辆故障数据分析与预防性维护报告

## 📌 项目简介

本项目基于 **Chinese Vehicle Fleet Fault Association Dataset**（中国车队故障协会数据集），对 2020~2023 年间中国部分维修设施的真实车辆维护记录进行系统性数据分析。通过 Python 数据清洗、SQLite 多表关联与可视化，探索车辆故障的分布规律与早期特征，为车企质量管控与预防性维护策略提供数据支撑。

**核心发现**：0~5,000km 区间存在显著的早期故障高峰（占总量约 30%），主要集中在动力系统与电气系统，符合可靠性工程"浴盆曲线"理论。

## 💡 核心业务结论

### 1. 0~5,000km 早期故障集中现象（最关键发现）

对 `fault_events` 的 `mileage_at_fault` 字段进行分布统计，发现 **0~5,000km 区间故障数达 3,003 条**，为全里程段最高峰值，占总量约 30%。

进一步下钻分析：
- **故障系统**：早期故障以 **动力系统（935 条，31%）** 和 **电气系统（437 条，15%）** 为主
- **严重程度**：3 级（严重）最多（1,004 条），其次为 2 级（938 条），并非轻微磨合问题
- **平均故障里程**：0~1,000km 区间平均仅 **518km**

**业务解读**：该分布符合可靠性工程 **"浴盆曲线"（Bathtub Curve）** 的早期故障期特征。新车在磨合阶段因制造缺陷、装配工艺或软件标定问题，存在显著的故障集中暴露现象。建议车企加强动力系统出厂台架测试与电气系统老化筛查，将早期故障拦截在交付前。

### 2. 传感器异常与故障严重程度强相关

对 `temperature_celsius` 与 `pressure_kpa` 进行异常分段后交叉分析：

| 温度状态 | 压力状态 | 故障数 | 平均严重程度 |
|----------|----------|--------|--------------|
| 高温异常（>110°C） | 正常 | 3,513 | 3.03 |
| 高温异常（>110°C） | 高压异常（>300kPa） | 1,372 | 2.97 |
| 正常 | 正常 | 15,463 | 2.45 |

**结论**：温度异常是故障严重程度的显著信号，可作为故障预警模型的重要输入特征。

### 3. 季节性故障特征

- **夏季（6~8 月）**：故障数达到全年峰值，8 月故障数接近 3,000
- **冬季（12 月）**：出现次高峰，与低温冷启动相关
- 动力系统在所有季节均为故障数最高的系统

**建议**：夏季应重点监控电气系统热管理，冬季加强启动系统维护。

### 4. 品牌故障率差异

各制造商故障率存在显著差异，部分品牌故障率明显高于平均水平，详细数据见 `analysis_brand_fault_rate.csv`。

### 5. 故障严重程度分布

严重等级分布呈"中间高两头低"：等级 3 > 等级 2 > 等级 1 > 等级 4 > 等级 5。
